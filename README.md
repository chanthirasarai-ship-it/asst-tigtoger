# Asst.tigtoger To-do app

A responsive, local-first to-do list application built with plain HTML, CSS, and JavaScript.

## Features

- Create tasks with high, medium, or low priority
- Mark tasks complete and delete individual tasks
- Filter by all, today, or completed
- Progress indicator and task counters
- Clear completed or delete all tasks
- Persists automatically in browser `localStorage`
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a browser. No build step or server is required.
